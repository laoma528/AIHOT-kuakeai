### 2. 阴影系统现代化

**旧系统** (多层色差）→ **新系统**（三级阴影）

```css
/* 浅色阴影 */
--shadow-subtle: 0 1px 2px rgba(0, 0, 0, 0.05)
--shadow-card: 0 1px 2px rgba(0, 0, 0, 0.05)        /* 卡片默认 */
--shadow-medium: 0 4px 12px rgba(0, 0, 0, 0.08)     /* 卡片 Hover */
--shadow-prominent: 0 12px 24px rgba(0, 0, 0, 0.12) /* 弹窗/对话 */

/* 深色阴影（更明显） */
--shadow-subtle: 0 1px 2px rgba(0, 0, 0, 0.3)
--shadow-medium: 0 4px 12px rgba(0, 0, 0, 0.4)
--shadow-prominent: 0 12px 24px rgba(0, 0, 0, 0.5)
```

**变化**：
- 移除了彩色阴影 `rgba(32,42,48,...)`
- 统一用黑色阴影（更现代、更专业）
- 深色模式阴影透明度提高（视觉分层更强）
