### 2. 隐私政策

**文件**: `industry/pages/privacy.md`

**核心内容**：

| 章节 | 内容 |
|---|---|
| **1. 浏览器本地数据** | 收藏、已读、主题、草稿都在本地，不上传 |
| **2. 主动提交的数据** | 反馈内容、邮箱、截图的处理和保留期（6 个月） |
| **3. 防滥用** | 无法还原的 IP + 浏览器标识，7 天自动删除 |
| **4. 服务器日志** | 服务商的政策适用，不做统计追踪 |
| **5. 模型数据处理** | 调用 Agnes AI 等模型，仅发送新闻内容 |
| **6. 第三方链接** | 原文链接属第三方，对方的隐私政策适用 |
| **7. 可选功能** | 飞书推送、R2 备份的隐私说明 |
| **8. 你的权利** | 访问、更正、删除、撤回同意（符合《个保法》） |
| **9. 联系方式** | ai@kuake.ai，承诺 30 天内回复 |

**特点**：
- ✅ 符合《中华人民共和国个人信息保护法》（PIPL）
- ✅ 明确了"不做统计追踪"和"不出售信息"
- ✅ 详细说明了模型服务商的数据处理
- ✅ 提供了用户权利行使方式

### 3. 使用规则

**文件**: `industry/pages/terms.md`

**核心内容**：

| 章节 | 内容 |
|---|---|
| **1. 内容说明** | 模型可能不准确、原文版权属来源、聚簇可能有误 |
| **2. 来源方权利** | 允许更正、下架、调整展示方式，24 小时处理 |
| **3. 使用规则** | 清晰的"允许/需要许可/禁止"三层分类 |
| **4. 接口使用** | RSS/API/MCP 的合理使用指南、禁止商业爬虫 |
| **5. 服务可用性** | 按"现状"提供，不保证 99.9% 可用性 |
| **6. 内容审核** | 接受举报，24 小时审核 |
| **7. 知识产权** | 网站设计、标题、摘要是我们的 IP |
| **8. 快速参考表** | 允许/需许可/禁止 一目了然 |

**使用规则三层分类**：

```
✅ 允许（无需许可）
  - 个人阅读、转发给朋友、分享链接
  - 在社交媒体提及 KuakeAI
  - 个人 RSS 订阅

⚠️ 需要许可
  - 商业产品集成
  - 公开渠道转载
  - 模型训练
  - API 直连用于商业

❌ 禁止
  - 冒充 KuakeAI
  - 隐藏出处标记
  - 大量爬虫下载
  - 违法用途
```

**特点**：
- ✅ 符合《著作权法》（保护聚簇、标题、摘要的 IP）
- ✅ 明确了来源方的下架权（24 小时承诺）
- ✅ 保护了商业模式（需许可的用途清晰）
- ✅ 提供了快速参考表（用户易理解）

## 📋 法律合规性检查清单

### 中国法律要求

| 法律 | 要求 | 我们的做法 |
|---|---|---|
| **《个人信息保护法》(PIPL) | 隐私政策、用户权利 | ✅ 完整隐私政策、用户可访问/更正/删除 |
| **《著作权法》** | 来源标注、版权声明 | ✅ 明确说明原文版权属来源、摘要是我们的 IP |
| **《反不正当竞争法》** | 不得冒充、隐瞒出处 | ✅ 禁止冒充、隐藏标记 |
| **《网络安全法》** | 用户信息安全 | ✅ HTTPS、备份、防滥用措施 |
| **内容审核** | 接受举报、及时处理 | ✅ 24 小时审核承诺 |

### 建议的后续步骤

| 项 | 建议 | 优先级 |
|---|---|---|
| **律师审阅** | 找熟悉互联网法的律师最终审核 | 🔴 必做 |
