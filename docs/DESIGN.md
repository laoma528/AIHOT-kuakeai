# AIHOT 设计系统

AIHOT 结合 OpenAI 的现代精致风格和 Notion 的卡片化设计，打造一个高级、和谐、舒适的热点站界面。

## 色彩体系

### 核心理念
- **强调色用翠绿** (`#10b981`)：代表生长、信任、生命力 — 与"热点"的持续更新相呼应
- **背景非纯白**：`#f9fafb`（极浅灰）在视觉上更舒适，减少眼睛疲劳
- **高对比卡片**：表面层用纯白，凸显内容的重要性
- **微妙阴影**：替代大量色差边框，呈现现代卡片感

## 阴影系统

替代多层色差的现代做法：用三级阴影表现深度和分层。

### 浅色阴影

```css
--shadow-subtle: 0 1px 2px rgba(0, 0, 0, 0.05);
--shadow-medium: 0 4px 12px rgba(0, 0, 0, 0.08);
--shadow-prominent: 0 12px 24px rgba(0, 0, 0, 0.12);
```

### 深色阴影

```css
--shadow-subtle: 0 1px 2px rgba(0, 0, 0, 0.3);
--shadow-medium: 0 4px 12px rgba(0, 0, 0, 0.4);
--shadow-prominent: 0 12px 24px rgba(0, 0, 0, 0.5);
```

## 组件设计原则

### 按钮

**主按钮（Primary）**
- 浅色：背景翠绿 `#10b981`，文字白
- 深色：背景翠绿 `#10b981`，文字白
- Hover：背景深翠绿 `#059669`

**次按钮（Secondary）**
- 浅色：背景 `#f3f4f6`，文字黑，边框 `#e5e7eb`
- 深色：背景 `#242d3d`，文字白，边框 `#374151`
- Hover：背景加深一档

**文字按钮（Tertiary）**
- 浅色：文字翠绿 `#10b981`，无背景
- 深色：文字翠绿 `#10b981`，无背景
- Hover：文字变深翠绿 `#059669`

### 卡片

- 背景：白色/深灰表面色
- 边框：几乎看不见的极浅边框或无边框
- 阴影：subtle 或 medium（不用 prominent）
- 圆角：8-12px（保持现有的 radius scale）

### 链接和强调

- 色彩：翠绿 `#10b981`
- Hover：下划线 + 文字变深翠绿
- 访问状态：降级到灰色

### 输入框

- 背景：浅色 `#ffffff` / 深色 `#1a1f2e`
- 边框：`#e5e7eb` (浅) / `#4b5563` (深)
- Focus：边框变强翠绿，阴影加 subtle
- Placeholder：文字弱色

## 响应式和暗色模式

### 主题切换

网站支持三种模式：
1. **浅色模式** — 用上表的浅色值
2. **深色模式** — 用上表的深色值
3. **跟随系统** — 根据 `prefers-color-scheme` 自动切换

用户可在 Sidebar 右上角切换，偏好保存到 localStorage。

### 减少动作模式

所有过渡动画检查 `prefers-reduced-motion: reduce`，保证无障碍。

## 排版

- **字体**：系统字体栈（保持现有）
- **行高**：1.6（可读性）
- **字号**：从 12px（标签）到 20px（标题）的标准阶梯

## 间距

沿用现有 Tailwind 的 4px 单位制，无改动。
